# Windows Legacy Archive

此目錄保存 2026-10-04 前的 Windows bridge、Dashboard、QR、PowerShell launcher、測試與操作文件，只供歷史追溯。

這些檔案不屬於目前 macOS active runtime，也不會由 `tools/start_mqtt_bridge.command`、ESP32 firmware 或 Global Dashboard 載入。若日後恢復 Windows 支援，應建立新的 branch 並重新驗證 Python dependencies、Firewall、LAN IP、MQTT 與 QR。
