# Dashboard QR 管理

| 資料夾 | 用途 |
|---|---|
| `current/` | 目前 bridge 透過 `/iphone_qr.png` 提供給 Dashboard 的唯一 QR |
| `macos/` | MacBook bridge 的 QR 保存檔 |
| `windows/` | Windows bridge 的 QR 保存檔與產生說明 |

Demo 前先確認 bridge host 的 LAN IP，產生對應平台 QR 後，複製 PNG 與 SVG 到 `current/`。不可把舊 Mac IP QR 用於 Windows bridge，或反過來使用。
